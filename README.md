## Как запускать

### 1. Подготовка окружения
1. Установите **VS Code** и расширения:
   * **PlatformIO IDE** — для написания и сборки кода.
   * **Wokwi simulator** — для запуска симуляции в редакторе.
2. Создайте новый проект PlatformIO для платы ESP32.

### 2. Настройка Wokwi CLI (для MacOS)
Для работы симулятора выполните в терминале VS Code следующие команды:
```bash
curl -L https://wokwi.com/ci/install.sh | sh
wokwi-cli init
```

### 3. Разработка проекта
1. Напишите код программы в файле `src/main.cpp` (при необходимости добавьте нужные библиотеки через вкладку *Libraries* в расширении PlatformIO).
2. Добавьте в корень проекта файл `diagram.json` со схемой компонентов (его можно экспортировать из веб-версии Wokwi).

### 4. Сборка и запуск
* **Сборка кода:** Нажмите кнопку **Build** (иконка галочки `✓` на нижней панели PlatformIO).
* **Запуск симуляции:** Откройте команду расширения Wokwi и выберите **Start Simulation**.
