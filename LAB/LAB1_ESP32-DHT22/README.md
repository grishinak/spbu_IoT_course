# ESP32 DHT project
Знакомство с ESP32 и датчиками температуры и влажности (DHT22)

# Init

1. download vscode plugins: 
    1. Platformio IDE
    2. Wokwi simulator

2. Create new platformio project.
in terminal (for MacOS):
> curl -L https://wokwi.com/ci/install.sh | sh 

> wokwi-cli init

3. write main.cpp code (can add libraries from platformio extension for tasks)

4. add diagram.json (e.g. from wokwi web)

- platformio vscode plugin: build V

- wokwi vscode plugin: start simulation
